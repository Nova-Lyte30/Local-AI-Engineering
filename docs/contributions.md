# 个人贡献、工具使用与证据边界

> 本文用于解释两个项目中个人参与的工作、所用第三方组件和 AI 辅助范围。依据现有本机核验记录和历史截图撰写，不凭事后文字认领无证据的代码作者身份。

## 项目一：开源模型本地部署与推理环境配置

| 工作类别 | 个人参与事项与证据范围 | 不主张的内容 |
| --- | --- | --- |
| 需求与方案 | 根据 Windows、RTX 4060 Laptop 8 GB 显存和 32 GB 内存条件，选择 GGUF 量化模型与 llama.cpp，提出多模型切换、参数管理和本机 API 的需求；参见[启动器审计](launcher-audit.md) | 自研模型架构、量化算法或 llama.cpp 推理引擎 |
| 部署与调试 | 使用本机启动器加载 Qwen IQ2_M 与 Cosmos Q8_0，配置 16384 上下文和 OpenAI 兼容 API，参与模型加载、错误诊断、短答与图片测试；参见[模型说明](model-deployment.md)与[端到端记录](../tests/evidence/start-bat-e2e-2026-10-21.md) | 对全部型号完成性能优化、无截断 16K、长期稳定运行 |
| 启动器脚本 | 提出需求、借助 AI 编程工具辅助设计和调整既有启动器，并实际使用；现存原始脚本的具体作者与逐行贡献缺少可核对的编辑差异 | 独立手写或原创完整 `llama-oneclick.ps1` 实现 |

## 项目二：本地 AI Agent 工作流搭建与应用

| 工作类别 | 个人参与事项与证据范围 | 不主张的内容 |
| --- | --- | --- |
| 集成配置 | 在 Cline Desktop 中连接本机 llama.cpp OpenAI 兼容接口，选择模型与隔离工作区；参见[工作流说明](agent-workflow.md) | 从零开发 Cline 客户端、工具执行系统或 Agent 框架 |
| 功能测试 | 设计并参与对话、文件、终端与多文件任务测试，提供历史运行截图和本机产物；参见[逐项验收记录](../tests/agent-acceptance-report.md) | 把历史截图中的总结视为独立验证通过，或声称 11 项全部完成 |
| 故障排查 | 记录路径偏离、文件编码/换行、PowerShell 引号与 16384 上下文超限问题，和 AI 辅助工具一起实施独立核验 | 声称所有文件任务均可靠成功、危险操作存在操作系统级沙箱保障 |

## AI 辅助与第三方依赖

- **第三方基础组件**：模型权重来自相应模型发布者，推理运行器为 [llama.cpp](https://github.com/ggml-org/llama.cpp)，Agent 客户端为 [Cline](https://github.com/cline/cline)。本仓库只展示集成实践及测试，不声称开发这些产品。
- **AI 辅助工作**：项目整理阶段使用 Codex 协助形成公开复现脚本、测试代码、文档结构、技术复核与测试报告。公开的 `scripts/llama-oneclick.example.ps1` 是整理后的安全示例，并非早期原始启动器。具体来源见[启动器审计](launcher-audit.md)。
- **证据归属**：本人提供的历史操作截图、原有本地脚本及测试文件与 Codex 后来独立执行的核验必须区分。SHA-256 仅验证文件字节，不证明作者身份。未保留的开发历史不通过编造提交记录补齐。
- **当前验证状态**：按[模型测试报告](../tests/model-test-report.md)、[Agent 验收报告](../tests/agent-acceptance-report.md)与[2026-10-22 P0 补测](../tests/evidence/agent-p0-recheck-2026-10-22.md)逐项判断。该补测中 Cline 创建和编辑了源码，但末尾换行未达标；ChatGPT 辅助编写、通过 Remote Desktop Commander 独立执行的外部校验脚本完成了受限修复，不应归类为 Cline 自主修复成功。失败、限制和待复测项目仍保留，不用叙述性措辞替代真实通过证据。

## 适合简历的表述边界

可写：本地模型选型与部署、配置 llama.cpp 和本机 API、Cline 对接、制定测试任务与排查文件/上下文问题。

应避免：独立研发 AI Agent 框架、实现可靠的全自动文件工作流、优化吞吐量提升某个百分比、实现完全离线安全沙箱、无截断的 16K 长上下文能力（除非新增独立证据）。

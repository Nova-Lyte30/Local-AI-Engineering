# 个人贡献和工具使用

> 本文阐述项目过程中个人参与的工作、所用第三方组件和 AI 辅助范围。依据现有本机核验记录和历史截图撰写，不凭事后文字认领无证据的代码作者身份。

## 项目一：开源模型本地部署与推理环境配置

| 工作类别 | 个人参与事项与证据范围 | 不主张的内容 |
| --- | --- | --- |
| 需求与方案 | 结合 Windows 11、RTX 4060 Laptop（8 GB 显存）与 32 GB 内存的硬件条件，选择适用于本机的 GGUF 量化模型，采用 llama.cpp 建立本地推理服务，并通过 OpenAI 兼容 API 进行调用；参见[模型部署说明](model-deployment.md) | 自研模型架构、量化算法或 llama.cpp 推理引擎 |
| 部署与调试 | 使用本机启动器分别加载 Qwen3.6-35B-A3B 社区改版的 IQ2_M 量化模型与 `Cosmos-Reason2-8B.Q8_0`，参与模型加载、API 请求、16,384-token 上下文配置、异常排查及短文本／静态图片测试；参见[模型说明](model-deployment.md)与[端到端复测](../tests/evidence/start-bat-e2e-2026-10-21.md) | 对全部型号完成性能优化、无截断 16K、长期稳定运行 |
| 启动器脚本 | 围绕硬件检测、模型目录扫描、启动自动化、模型选择与参数管理提出需求，结合 Cursor 等 AI 编程工具辅助编写、调整并使用本地启动脚本。现存启动器包含上述逻辑，两个模型已分别通过原始 `start.bat` 加载与 API 复测；具体代码作者及逐行修改记录尚不能独立确认。参见[启动器审计](launcher-audit.md) | 独立手写或原创完整 `llama-oneclick.ps1` 实现 |

## AI 辅助与第三方依赖

- **第三方基础组件**：模型权重来自相应发布者，推理运行器为 [llama.cpp](https://github.com/ggml-org/llama.cpp)，Agent 客户端为 [Cline](https://github.com/cline/cline)。本仓库只展示集成实践及测试，不声称开发这些产品。
- **AI 辅助工作**：项目整理与完善借助 Codex 协助，形成公开的复现脚本、测试代码、文档结构、技术复核与测试报告。公开的 `scripts/llama-oneclick.example.ps1` 是整理后的安全示例，并非早期原始启动器。具体来源见[启动器审计](launcher-audit.md)。
- **证据归属**：本人提供的历史操作截图、原有本地脚本及测试文件与 Codex 后来独立执行的核验必须区分。SHA-256 仅验证文件字节，不证明作者身份。未保留的开发历史不通过编造提交记录补齐。
- **当前验证状态**：按[模型测试报告](../tests/model-test-report.md)、[Agent 验收报告](../tests/agent-acceptance-report.md)与[2026-10-22 P0 补测](../tests/evidence/agent-p0-recheck-2026-10-22.md)逐项判断。该补测中 Cline 创建和编辑了源码，但末尾换行未达标；ChatGPT 辅助编写、通过 Remote Desktop Commander 独立执行的外部校验脚本完成了受限修复，不应归类为 Cline 自主修复成功。失败、限制和待复测项目仍保留，不用叙述性措辞替代真实通过证据。
